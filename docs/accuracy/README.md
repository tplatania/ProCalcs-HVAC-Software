# BOM Accuracy Handoff

This folder is the continuing quality record for the Reliable BOM pilot. The product Definition of Done controls pilot release. The Accuracy Definition of Done controls the initial certification, ownership transfer, regression discipline, and recurring review of BOM output quality.

Nothing here relaxes Catherine's v1 scope: built `.rup` files, conventional non-Rheia residential jobs, deterministic generation, materials only, Reliable's cost sheet only, no markup, and no silent gaps.

## Records

- `definition-of-done.md` — handoff and continuing quality gates.
- `corpus-manifest.md` — Richard's eight projects plus two incomplete files.
- `evaluation-record.md` — item, quantity, gap, and price comparison for one run.
- `disagreement-log.md` — unresolved takeoff/rule differences.
- `change-review.md` — approval record for a proposed rule change.
- `monthly-scorecard.md` — recurring pilot-quality review.

## Authority

- Catherine authorizes pilot release and quality-policy changes.
- Richard is the accuracy authority for items, quantities, and domain rulings.
- Catherine and Dana own wrong-BOM reports and the one-business-day response.
- Gerald maintains evaluation tooling and release evidence until handoff is accepted.

Corrections never become live rules automatically. They require Richard's ruling where domain behavior changes, a versioned change, and a full frozen-corpus regression.
